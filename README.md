# rally.raid Earth

Dakar-style rally raid for [BeamNG.Earth](https://github.com/tecnagamer/beamng.earth): plot a stage on a real map, make a roadbook, and race it in BeamNG.drive with a rally GPS, a scrolling roadbook, repairs, and a way to recover a stuck car or resume after the game crashes.

The public website (no login) is **[rrearth.wyans.net](https://rrearth.wyans.net)**. It moved from stagebuilder.wyans.net on 17 Nov 2026; old links redirect, and saved work in the browser is copied over on the first visit.

Source code: **[github.com/wyans-r/rally.raid-earth](https://github.com/wyans-r/rally.raid-earth)** (MIT).

This is a fan project. It is not an official BeamNG, FIM or FIA product. You need [BeamNG.Earth](https://github.com/tecnagamer/beamng.earth) installed for the stages to sit on the real world.

**Async Events** (online organised events, logins, official result uploads) is not released yet. The public website has no Events section. The public mod zip leaves that app out.

## 1. Install the mod

1. You need BeamNG.drive and BeamNG.Earth installed and working.
2. Find the BeamNG user folder. On Windows, paste this into File Explorer's address bar: `%LOCALAPPDATA%\BeamNG\BeamNG.drive\current`
3. Copy the mod zip into the `mods` folder inside that `current` folder. The zip itself is the mod — do not unzip it there. (The public file is named `rallyraid_earth.zip`. Keep that name when you update, so the new zip replaces the old one.)
4. Start the game, turn the mod on in the Mod Manager if it is not already, load BeamNG.Earth, and spawn a car.

To edit the files yourself: unzip to `...\current\mods\unpacked\rallyraid\` so that folder contains `lua`, `scripts`, `ui`, `rallyraid` and `settings`. After a change, press Ctrl+L to reload Lua, or restart the game.

## 2. Put the apps on the HUD

1. Press Esc, then **UI Apps**.
2. **Add app**, search **rally.raid**. Add **GPS**, and if you want them: **Roadbook** and **Planner**. (Or press **MENU** > **RALLY LAYOUT** (GPS + Roadbook) or **PLANNER LAYOUT** (GPS + Roadbook + Planner) in the GPS app.)
3. Drag each app where you want it; resize from the corner.

You may need to move the mouse to click buttons while driving. The driving keys (trip, W, roadbook scroll and sync) are in section 5. You can hide BeamNG.Earth's own minimap if you want to navigate by roadbook and GPS only; this mod cannot turn it off for you.

## 3. Build a stage (website)

Open [rrearth.wyans.net](https://rrearth.wyans.net) in Chrome, Edge or Firefox (it needs internet for the map, routing and search).

1. **Examples** (on the Guide tab) loads a sample you can edit. The first change blanks the example's name so you do not overwrite the sample by accident.
2. Search a place, or type `lat, lon`. The layer button (top right) switches OpenStreetMap, terrain and satellite.
3. Pick a point type (start with **DSS**, the stage start), then click the map. Drag markers to move them.
   - **New leg follows**: *roads* uses car routing; *tracks & paths* follows small OpenStreetMap tracks (a stretch with no track is drawn dotted red); *my loaded GPX track* follows a file you imported; *straight line* is off-piste.
   - **Insert after selected** adds a point between two existing ones. **Clear all** empties the route (you can undo once).
4. On the **Stage** tab, fill the name and description, or press **Generate name and description** (uses real nearby place names only).
5. On the **Rules** tab, the defaults follow FIM 2026. Change them if your event uses other regulations; the file carries the rules with it.
6. **File** tab: export the stage `.json`, import a file, or copy a share link (the link carries the stage itself; nothing is uploaded).
7. Press **Roadbook** to generate and edit the roadbook, then save `<stage id>.roadbook.json`.

**Route** points (saved in the file as type `NOTE`) shape the line and get a roadbook box, but they are not GPS waypoints. A yellow forest warning means a leg goes through thick trees with no mapped track along that line.

Put stage files in `<BeamNG user folder>/current/rallyraid/stages/` and roadbooks in `.../current/rallyraid/roadbooks/` (create the folders). A shareable "stage pack" can also be a zip whose top-level folder is `rallyraid/stages/`.

## 4. Race a stage

1. On the GPS app, press **STAGES**, pick a stage, **LOAD**. Broken files show in red with the reason.
2. **TP TO DSS** teleports you to the start through BeamNG.Earth, or drive there: before the start the GPS always points to the DSS.
3. In the DSS circle, press **START** (5 s countdown) or just drive off: with the default start mode the clock starts when you leave the circle. Leaving during the countdown is a false start.
4. Navigate. The GPS always shows **CAP** (your heading) and speed. The next waypoint's distance and heading appear only inside its reveal radius (a Visible waypoint is shown all the time; a Control waypoint never shows a distance).
5. **Trip** is the odometer you match to the roadbook: **+** / **−** correct it, **0** resets it (the reset key is not bound by default). **PART** is a partial you reset at each box. When you take a waypoint, the trip snaps to that box's km.
6. **Speed zones**: once you have passed the start of a zone, going over the limit adds time (impulses). The bar warns you and flashes red when you are over.
7. Validating the **ASS** (finish) stops the clock. The result is saved. Teleporting during a stage marks the result unofficial. **ABORT** restarts the stage.

## 5. Keys and buttons

Only the things you do while driving have default keys. Everything else is a button in the apps, so nothing clashes with BeamNG's own keys. Rebind any of them in Options > Controls > Bindings, search "rally.raid"; a wheel or handlebar button works too, and the apps show the key you set. The defaults (checked against `mod/settings/inputmaps/keyboard_rallyRaid.json`):

| Action | Default key |
|---|---|
| Trip + / trip − (hold to repeat) | Ctrl+Shift+Up / Ctrl+Shift+Down |
| W+ (skip waypoint) / W− (back to a missed one) | Ctrl+Shift+Right / Ctrl+Shift+Left |
| Partial reset | Ctrl+Shift+P |
| Start countdown | Ctrl+Shift+Home |
| Roadbook box up / down | Ctrl+Shift+PageUp / Ctrl+Shift+PageDown |
| Sync trip to the box on screen | Ctrl+Shift+End |
| Trip reset | not bound by default (**0** on the GPS app) |
| Start a new rally (recoveries / resets back to 0) | not bound by default |

No default key, a button instead:

| Action | Button |
|---|---|
| Repair menu | GPS app **MENU** > **REPAIR** |
| Recover car (two steps: see the penalty, then confirm) | GPS app **MENU** > **RECOVER**, then **CONFIRM**; or **RECOVER CAR** in the GPS app's REPAIR panel |
| Resume after a game crash (two steps; then GO if the clock is held) | GPS app **MENU** > **RESUME**, then **CONFIRM RESUME** (the menu opens by itself when a save is found); or the GPS app's REPAIR panel |
| Planner: open / close | GPS app **MENU** > **PLANNER**, or click the Planner app's bar |
| Planner: waypoint here / roadbook box here / record the driven line | **ADD HERE** / **+ BOX HERE** / **REC** in the Planner app |
| Recce mode on / off | **RECCE** in the Planner app's bar, then **RECCE ON** / **OFF** |
| Recce: drop a box here, confirm, move here, retag, delete the nearest box, undo | **+ BOX HERE**, **✓**, **HERE**, **TAG**, **✕**, **UNDO** in the Planner app's RECCE panel (also ◀ ▶ / AT TRIP / NEAREST, KM = TRIP, -10 / +10, CAP HERE, note presets, CHANGES with UNDO per change, REPORT, MERGE) |

Trip step size (10 / 100 / 1000 m) is the **10m** button on the GPS app, not a key.

## 6. Repair, recover, resume

In the GPS app, press **MENU** > **REPAIR**. (There is no separate Repair app any more: it is the GPS app's REPAIR panel.)

- Mid-stage, standing still: change a wheel, fix one corner's suspension, or fix the radiator. The time is added to the stage.
- After the finish, the bivouac opens: whole-car repair and engine change from a time budget.
- During a stage, BeamNG's own reset keys are blocked. A reset the app did not make counts as a car recovery.
- **Stuck or rolled?** GPS app **MENU** > **RECOVER**, then **CONFIRM** (or **RECOVER CAR** in the REPAIR panel), sets the car upright back on the route a short way behind, damage kept, with a time penalty (+15 min first, +30 min each after). No limit on how many.
- **The game crashed?** The stage is saved to disk on a short heartbeat and at each waypoint. After you relaunch, load the stage: the GPS app's menu opens with the save; press **RESUME**, then **CONFIRM RESUME** (or use **Resume from last save** in the GPS app's REPAIR panel). There is no time penalty, but the result is flagged for the organiser to review.

Details: [docs/REPAIR.md](docs/REPAIR.md).

## 7. Recce and the in-game planner

**Recce.** Load a stage, then in the Planner app press **RECCE** and **RECCE ON**. It works on the stage the game has loaded, and every edit shows in the Roadbook app at once. The line you drive, and jumps, crests, compressions, soft sand and slopes the car finds, are recorded. You can drop, move, retag and delete boxes as you go with the RECCE panel's buttons. The file lands in `<BeamNG user folder>/current/rallyraid/recce/`. Merge it in the game, or import it in the roadbook editor.

**Planner.** Add **rally.raid Earth Planner** and click its bar (or **MENU** > **PLANNER** in the GPS app). Start a new stage, record the line you drive (**REC**), drop waypoints (**ADD HERE**) and roadbook boxes (**+ BOX HERE**), generate a roadbook, then save and load it into the rally computer. Files are the same ones the website uses, in `rallyraid/stages/` and `rallyraid/roadbooks/`. More detail: [docs/INGAME_PLANNER.md](docs/INGAME_PLANNER.md).

## 7b. Rally mode and the calendar (EXPERIMENTAL – not yet tested in game)

A **rally** is a multi-day event: bivouacs, liaisons and one special stage per day ([docs/RALLY_FORMAT.md](docs/RALLY_FORMAT.md)).
The first one is **Atlantic to Atlas 2027** (Portugal and Morocco, 9 to 23 January 2027). Inspired by the 2027 Dakar route. Unofficial, not affiliated.
Its special stages are 22 to 490 km long. Stage-Gen builds anything over about 185 km as a chain of parts (`stage-builder/stage-chain.js`).

In the game, add **rally.raid Earth Rally**. Pick a rally, then do each liaison with **DRIVE** (unused allowance goes to that evening's bivouac) or **TELEPORT** (the whole allowance counts as used).
Drive the stage, repair at the bivouac (GPS **MENU** > **REPAIR**), and press **NEXT DAY** (GPS **MENU** > **RALLY**). There are buttons only and no keys. **EXPERIMENTAL – not yet tested in game.** Rally mode is the GPS app's **RALLY** panel (it shows only in a build with rally mode). The first event (Atlantic to Atlas 2027) and the calendar page come out only after the in-game check.
The website calendar is `calendar.html` (not live yet).

Makers: `node tools/rally-batch.js rallies/specs/<id>.spec.json` (generate every stage in the background; resumable), then
`node tools/rally-compile.js rallies/specs/<id>.spec.json` (check, write the rally file to the website and the mod). Tests: `node --test tests/rally.test.js`,
`tests/run_tests.py rally_test.lua`, `node tests/browser/rally_test.js`.

## 8. Build a public zip (for maintainers)

From this repository:

```sh
python3 scripts/build_public_zip.py
```

That writes `dist/rallyraid_earth.zip` with the correct BeamNG folder layout (`lua`, `ui`, `scripts`, `settings`, `rallyraid` at the zip root). The official-event Lua is left out. The **rally.raid Earth Event** app (a COMING SOON placeholder) is never in a zip, so every build has the three HUD apps. The script does not put the zip on the website or on BeamNG.com.

For a private build that includes the unreleased Events Lua:

```sh
python3 scripts/build_public_zip.py --include-events --output dist/rallyraid_earth_dev.zip
```

Rally mode (EXPERIMENTAL – not yet tested in game) goes in with `--include-rally` (rally.lua and the GPS app's RALLY panel styles). Rally files (`rallyraid/rallies/`, the Atlantic to Atlas 2027 event) only go in with `--include-rally-events` too, after the in-game check.

Do not include a README inside a zip you submit to BeamNG.com — their rules ask you to put the description on the listing instead.

## 9. Bug reporting

1. Press `~` in the game to open the console, and take a screenshot of any red errors.
2. Note the BeamNG.drive version, the BeamNG.Earth version, and what you were doing (which stage, which app, which key).
3. If you can, attach the stage `.json` and the roadbook file (or a share link from the website).
4. Open an issue at [github.com/wyans-r/rally.raid-earth/issues](https://github.com/wyans-r/rally.raid-earth/issues), or report it to wyans on the BeamNG.Earth Discord.

Please do not paste secret keys (Cloudflare, Discord, email, or anything similar) into an issue or a chat.
