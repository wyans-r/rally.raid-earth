Rally Raid for BeamNG.drive

Dakar-style rally raid for BeamNG.Earth: a GPS with CAP and odometer that follows the FIM reveal rules, a scrolling roadbook, timed stages with penalties, and a recce mode for refining notes as you drive.

Download rallyraid_mod.zip
Test build, 16 Nov 2026 · about 490 KB · includes 15 example stages with roadbooks
This is an early test build that has not yet been tested much in game. Requires BeamNG.drive with the BeamNG.Earth mod installed and working.

Install

  1. Close BeamNG.drive.
  2. Paste %LOCALAPPDATA%\BeamNG\BeamNG.drive\current\mods\ into the File Explorer address bar and press Enter.
  3. Put rallyraid_mod.zip in that folder without unzipping it. When updating, replace the old zip.
  4. Start the game, check the mod is on in the Mod Manager, load BeamNG.Earth and spawn a car.
  5. Press Esc, open UI Apps, choose Add app and add Rally Raid GPS and Rally Raid Roadbook (category "Rally Raid"). Drag and resize them to taste.

Race a stage

  1. On the GPS app press STAGES (or BOOK on the roadbook app), click a stage and press LOAD, or double-click it.
  2. Press TP TO DSS to teleport to the start, or drive there; the GPS points to the start until the stage begins.
  3. Drive out of the start circle to start the clock, then navigate by roadbook. The GPS shows waypoint distance and heading only when you get close, as in a real rally.

Keys

Ctrl+Shift+Up / Downtrip meter up / down
Ctrl+Shift+Left / Righttrip step size
Ctrl+Shift+Preset partial
Ctrl+Shift+PageUp / PageDownscroll roadbook boxes
Ctrl+Shift+End"I'm at this box": set the trip to its km
Ctrl+Shift+Rrecce mode on / off
Ctrl+Shift+Nrecce: new box here
Ctrl+Shift+Zrecce: undo

Make your own stages

Plot a route in the stage builder (the Examples button loads samples to learn from), export the stage .json, then make its roadbook in the roadbook editor. Put stage files in %LOCALAPPDATA%\BeamNG\BeamNG.drive\current\rallyraid\stages\ and roadbooks in ...\current\rallyraid\roadbooks\ (create the folders).

Something broken?

Press ~ in game to open the console and screenshot any red errors.
