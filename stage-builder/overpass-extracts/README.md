# Bundled Overpass extracts

Compressed OpenStreetMap extracts for the 15 example stage regions, used by the stage builder when `askOverpass` can answer a query from local data instead of a public Overpass server.

Rebuild with:

    node stage-builder/scripts/build-overpass-extracts.js

Data: © OpenStreetMap contributors, [ODbL](https://opendatacommons.org/licenses/odbl/).
The compressed files are not stored in this repository (rebuild them with the command above). They were first deployed to the website on 17 Nov 2026.
