Rally Raid for BeamNG.drive

Dakar-style rally raid for BeamNG.Earth: a GPS with CAP and odometer that follows the FIM reveal rules, a scrolling roadbook, timed stages with penalties, and a recce mode for refining notes as you drive.

Download rallyraid_mod.zip
Test build of 16 Nov 2026 · includes 15 example stages with roadbooks. Repair, Recover car, crash resume and the Planner (marked next build below) are not in this download yet; they come with the next public zip after in-game testing.
This is an early test build that has not yet been tested much in game. Requires BeamNG.drive with the BeamNG.Earth mod installed and working.

Install

  1. Close BeamNG.drive.
  2. Paste %LOCALAPPDATA%\BeamNG\BeamNG.drive\current\mods\ into the File Explorer address bar and press Enter.
  3. Put rallyraid_mod.zip in that folder without unzipping it. When updating, replace the old zip.
  4. Start the game, check the mod is on in the Mod Manager, load BeamNG.Earth and spawn a car.
  5. Press Esc, open UI Apps, choose Add app and add Rally Raid GPS and Rally Raid Roadbook (category "Rally Raid"). In the next build you can also add Rally Raid Repair and Rally Raid Planner. Drag and resize them to taste.

Race a stage

  1. On the GPS app press STAGES (or BOOK on the roadbook app), click a stage and press LOAD, or double-click it.
  2. Press TP TO DSS to teleport to the start, or drive there; the GPS points to the start until the stage begins.
  3. Drive out of the start circle to start the clock, then navigate by roadbook. The GPS shows waypoint distance and heading only when you get close, as in a real rally.

Keys

These are the defaults shipped in the mod. Keys marked next build are not in the 16 Nov download yet. (Rebind them in Options > Controls > Bindings, search "Rally Raid".)

Ctrl+Shift+Uptrip + (hold to repeat)
Ctrl+Shift+Downtrip − (hold to repeat)
Ctrl+Shift+LeftW− (back to a missed waypoint)
Ctrl+Shift+RightW+ (skip waypoint)
Ctrl+Shift+Preset the partial odometer
Ctrl+Shift+Homestart the 5 s countdown (stand in the start circle)
Ctrl+Shift+PageUproadbook box up (the trip is not changed)
Ctrl+Shift+PageDownroadbook box down (the trip is not changed)
Ctrl+Shift+Endsync the trip to the box on screen (“I am at this box”)
Ctrl+Shift+Rrecce mode on / off
Ctrl+Shift+Nrecce: drop a box here (press again to save it as it is)
Ctrl+Shift+Crecce: confirm the nearest box
Ctrl+Shift+Mrecce: move the nearest box here
Ctrl+Shift+Trecce: retag the nearest box
Ctrl+Shift+Deleterecce: delete the nearest box
Ctrl+Shift+Zrecce: undo
Ctrl+Shift+Frepair menu (next build)
Ctrl+Shift+Grecover car (press again to confirm) (next build)
Ctrl+Shift+Hresume after a game crash (press twice: once to see the save, again to resume; then GO if the clock is held) (next build)
Ctrl+Shift+Jplanner: open / close (next build)
Ctrl+Shift+Wplanner: waypoint here (next build)
Ctrl+Shift+Bplanner: roadbook box here (next build)
Ctrl+Shift+Kplanner: record the driven line on / off (next build)

Trip step size (10 / 100 / 1000 m) is the 10m button on the GPS app, not a key. Trip reset and start a new rally have no default keys; you can bind them in Options > Controls.

Make your own stages

Plot a route in the stage builder (the Examples button loads samples to learn from), export the stage .json, then make its roadbook in the roadbook editor. Put stage files in %LOCALAPPDATA%\BeamNG\BeamNG.drive\current\rallyraid\stages\ and roadbooks in ...\current\rallyraid\roadbooks\ (create the folders).

Something broken?

Press ~ in game to open the console and screenshot any red errors.
