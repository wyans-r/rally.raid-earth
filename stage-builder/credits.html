OpenStreetMap

Roads, tracks, paths, places, landmarks, and any stage or roadbook generated from them. © OpenStreetMap contributors, licence: Open Database Licence (ODbL).

Nominatim (place search and auto-generated names)

The public search service at nominatim.openstreetmap.org, used when you search for a place and when the builder fills a stage name from nearby places. Their usage policy asks for no more than one request a second; automatic name lookups here are spaced at least 1.1 seconds apart.

OSRM (car routing)

“Roads (car routing)” legs are routed by the public OSRM demo server at router.project-osrm.org. That server is a courtesy, with no uptime promise; treat it as fair use (about one request a second).

Overpass API (OpenStreetMap questions)

Used for “tracks & paths” legs, roadbook landmarks and junctions, and Stage-Gen. Queries go to public Overpass mirrors, including NextGIS Overpass, overpass-api.de, overpass.private.coffee, maps.mail.ru, and regional extracts on ovp.dresel.systems and overpass.osm.ch. The data they return is still OpenStreetMap data (ODbL). Answers are cached in your browser; a server that is silent or full is skipped.

Elevation

Primary: Mapterhorn terrain tiles, built from open digital elevation models. The global baseline is Copernicus GLO-30 (produced by DLR and Airbus, provided under Copernicus by the European Union and ESA). Regional sources and their licences: mapterhorn.com/attribution.

Fallback: Mapzen / Tilezen Terrarium tiles hosted on AWS. Source credits: Tilezen attribution.

Roadbook symbols and rules

Waypoint types, radii and penalties follow the public 2026 FIM World Rally-Raid Championship sporting regulations, which you can change per stage on the Rules tab. The symbols drawn in the editor and in the game are a compact, unofficial set made for this project in the style of the public FIM / FIA / Dakar lexicons. This is not official FIM or FIA artwork, and those organisations have not endorsed the project.

BeamNG.Earth

The game world, the live latitude / longitude, and the roads you drive are from BeamNG.Earth. You need BeamNG.Earth installed for the GPS and stages to make sense.
