## Draft description (for the repository overview)

rally.raid Earth is a Dakar-style navigation pack for BeamNG.Earth. Plot a stage on a real-world map, generate a roadbook, and race it in BeamNG.drive with a rally GPS that hides waypoints until you are close, a scrolling roadbook, timed penalties, mid-stage repairs, and a way to recover a stuck car or resume after the game crashes.

**You need BeamNG.Earth installed.** This is a fan project, not an official BeamNG, FIM or FIA product.

**Install.** Download the zip and drop it into your BeamNG mods folder (`%LOCALAPPDATA%\BeamNG\BeamNG.drive\current\mods` on Windows). Turn the mod on in the Mod Manager, load BeamNG.Earth, spawn a car. Press Esc → UI Apps → Add app, and add **rally.raid Earth GPS**. Also add **rally.raid Earth Roadbook**, **rally.raid Earth Planner** and **rally.raid Earth Repair** if you want them.

**Build or pick a stage.** Use the free website [stagebuilder.wyans.net](https://stagebuilder.wyans.net) (no login). The Examples list on the Guide tab loads sample stages. Export the stage `.json` and, if you want a roadbook, save the `.roadbook.json` from the roadbook editor. Put stages in `<BeamNG user folder>/current/rallyraid/stages/` and roadbooks in `.../roadbooks/`. The mod also ships 15 sample stages. The examples and their roadbooks are auto-generated by the stage builder; hand-made (curated) examples are still to come.

**Race.** Load a stage from the GPS, teleport or drive to the start, and go. The GPS always shows your heading (CAP) and speed. Distance to a hidden waypoint appears only when you are close, the way a real rally GPS works. The roadbook scrolls with your trip odometer.

**Keys while driving** (rebind in Options → Controls → Bindings, search "rally.raid"):

- Ctrl+Shift+Up / Down — trip + / − (hold to repeat)
- Ctrl+Shift+Right / Left — W+ (skip a waypoint) / W− (back to a missed one)
- Ctrl+Shift+PageUp / PageDown — scroll the roadbook; Ctrl+Shift+End — sync the trip to the box on screen
- Ctrl+Shift+P — reset the partial; Ctrl+Shift+Home — start countdown

**Everything else is a button**, so nothing clashes with BeamNG's own keys: the GPS app's **MENU** has REPAIR, RECOVER (stuck or rolled car: press, then CONFIRM), RESUME after a game crash, and PLANNER. Recce has buttons in the Roadbook app, the planner in its own app. You can still bind any of these in Options → Controls.

**Experimental / untested.** These are in the zip but have not been tested in game yet: Repair (the Repair app and repair menu), Recover car, crash resume, the Planner app, the GPS app's MENU panel, recce mode (the Roadbook app's RECCE panel), the apps showing your own key bindings, and whether a Ctrl+Shift key also fires BeamNG's own action for the plain key. The GPS and Roadbook apps have been driven on a full stage.

A full key list and a longer how-to are on the website's [mod page](https://stagebuilder.wyans.net/mod) and in the project README.

**Credits.** Map data © OpenStreetMap contributors (ODbL). Land cover © ESA WorldCover project / Contains modified Copernicus Sentinel data (2021) processed by ESA WorldCover consortium (CC BY 4.0). Built for BeamNG.Earth. Full credits: https://stagebuilder.wyans.net/credits.html

**Bugs.** Please report them with a console screenshot (`~` in game), your BeamNG and BeamNG.Earth versions, and the stage file if you can share it.

### Note about the `rallyraid/` folder

BeamNG's packing page lists official top-level folders such as `lua`, `ui`, `scripts`, `settings`, `vehicles` and `levels`. This zip also has a top-level `rallyraid/` folder for stages, roadbooks and (later) user files, because the Lua looks for `/rallyraid/stages/` and the same path in the user's `current` folder. That is deliberate, and it is how the mod finds shipped samples. It is not on the published list of folder names. If a reviewer objects, we should ask them before moving the files (a move would break the documented install path).

### Zip filename

`rallyraid_mod.zip` is a bit generic and could clash with someone else's file. wyans chose **`rallyraid_earth.zip`** on 17 Nov 2026 (it matches the project name rally.raid Earth; it replaced the earlier pick `wyans_rallyraid.zip`). It should not change later. The old `/download/rallyraid_mod.zip` stays on the site so old links still work, but nothing links to it.

## Submission steps (for later — do not do these now)

1. wyans says to submit (the website already offers `rallyraid_earth.zip` with the untested parts marked experimental). Keep the experimental note in the description until those parts are tested in game.
2. Build `rallyraid_earth.zip` with the public build script and check the folder layout.
3. Confirm the zip name, the title, and the description.
4. Log into beamng.com, go to Resources, **Add Resource**, pick a category (Utility / UI is the closest fit; confirm on the form), fill title, tagline, version (start at 0.2.0 or 1.0.0 as wyans prefers), description, tags.
5. Upload the zip. Tick **Upload Resource Icon** and add the 96×96 image. Add at least two screenshots with **Upload Images**.
6. Wait for review. Do not also upload a second copy under a different zip name.
