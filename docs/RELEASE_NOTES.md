# rally.raid Earth 0.2.0 (17 Nov 2026)

Dakar-style rally raid for [BeamNG.Earth](https://github.com/tecnagamer/beamng.earth). It gives you a rally GPS with CAP and odometer that follows the FIM reveal rules, a scrolling roadbook, timed stages with penalties, and repairs. Plot your own stages for free at **[rrearth.wyans.net](https://rrearth.wyans.net)** (no login).

This is an early build. You need **BeamNG.drive** with the **BeamNG.Earth** mod installed and working. The GPS and Roadbook apps have been driven on a full stage in game. Everything marked **EXPERIMENTAL / UNTESTED** below has not been tested in game yet.

## Download

`rallyraid_earth.zip` (below, under Assets). It includes 15 example stages; the examples and their roadbooks are auto-generated by the stage builder.

## Install

1. Close BeamNG.drive.
2. Open your mods folder:
   - Windows: paste `%LOCALAPPDATA%\BeamNG\BeamNG.drive\current\mods\` into the File Explorer address bar and press Enter.
   - In general: `<BeamNG user folder>/current/mods/`.
3. Put `rallyraid_earth.zip` in that folder **without unzipping it**. When you update, replace the old zip and keep the same filename.
4. Start the game, check the mod is on in the Mod Manager, load **BeamNG.Earth** and spawn a car.
5. Press Esc, open **UI Apps**, choose **Add app** and add **rally.raid Earth GPS** and **rally.raid Earth Roadbook** (category "rally.raid Earth"). If you want them, also add **rally.raid Earth Repair**, **rally.raid Earth Planner** and **rally.raid Earth Rally** (all EXPERIMENTAL / UNTESTED).

Stage files you export from the website go in `%LOCALAPPDATA%\BeamNG\BeamNG.drive\current\rallyraid\stages\` and roadbooks go in `...\current\rallyraid\roadbooks\` (create the folders).

## Race a stage

1. On the GPS app, press **STAGES** (or **BOOK** on the Roadbook app). Click a stage and press **LOAD**, or double-click it.
2. Press **TP TO DSS** to teleport to the start, or drive there. The GPS points to the start until the stage begins.
3. Drive out of the start circle to start the clock, then navigate by the roadbook. As in a real rally, the GPS shows waypoint distance and heading only when you get close.

## Keys (the 9 default keys)

Rebind them in Options > Controls > Bindings (search "rally.raid").

| Key | Action |
|---|---|
| `Ctrl+Shift+Up` | trip + (hold to repeat) |
| `Ctrl+Shift+Down` | trip − (hold to repeat) |
| `Ctrl+Shift+Left` | W− (back to a missed waypoint) |
| `Ctrl+Shift+Right` | W+ (skip waypoint) |
| `Ctrl+Shift+P` | reset the partial odometer |
| `Ctrl+Shift+Home` | start the 5 s countdown (stand in the start circle) |
| `Ctrl+Shift+PageUp` | roadbook box up (the trip is not changed) |
| `Ctrl+Shift+PageDown` | roadbook box down (the trip is not changed) |
| `Ctrl+Shift+End` | sync the trip to the box on screen ("I am at this box") |

The trip step size (10 / 100 / 1000 m) is set with the **10m** button on the GPS app, not a key.

## Buttons (no default key)

Everything else is a button in the apps, so it can't clash with BeamNG's own keys. You can still bind any of them in Options > Controls.

- **MENU → REPAIR** (GPS app) or the Repair app's bar: repair menu (EXPERIMENTAL / UNTESTED)
- **MENU → RECOVER** (GPS app) or **RECOVER CAR** (Repair app): recover car. Press once to see the penalty, then **CONFIRM** (EXPERIMENTAL / UNTESTED)
- **MENU → RESUME**: resume after a game crash with **RESUME**, then **CONFIRM RESUME**; press **GO** if the clock is held (EXPERIMENTAL / UNTESTED)
- **MENU → PLANNER** or the Planner app's bar; **ADD HERE**, **+ BOX HERE**, **REC**: the in-game planner (EXPERIMENTAL / UNTESTED)
- **RECCE** (Roadbook app) and its panel (**+ BOX HERE**, ✓, **HERE**, **TAG**, ✕, **UNDO**): recce mode (EXPERIMENTAL / UNTESTED)
- **Rally app**: **DRIVE** / **TELEPORT** for liaisons, **CHECK IN**, **LOAD STAGE**, **TP TO DSS**, **NEXT DAY**, **RESTART** (EXPERIMENTAL / UNTESTED)

## Experimental / untested

These are in this download but have **not been tested in game yet**. They may not work, or may behave oddly. Please report what you find.

- **Repair**: the Repair app and the repair menu (repair times, bivouac repairs, reset penalties).
- **Recover car**: puts the car back on the route for a time penalty (RECOVER, then CONFIRM).
- **Crash resume**: carries on a stage after the game crashed (RESUME, then CONFIRM RESUME).
- **Planner**: the Planner app (waypoints, roadbook boxes, recording your driven line in game).
- **GPS MENU**: the MENU panel on the GPS app.
- **Recce mode**: the RECCE panel on the Roadbook app.
- **Your own keys in the apps**: the apps show the key you bound instead of the default.
- **Rally mode**: the rally.raid Earth Rally app, for multi-day rallies. You drive each liaison against a time allowance or teleport (the whole allowance is then counted). There is bivouac repair time, marathon refuges and rest days, and the app keeps your cumulative time. Buttons only. No rally files ship in this zip yet.
- **Ctrl+Shift keys**: not yet checked whether a Ctrl+Shift key also fires BeamNG's own action for the plain key. If it does, rebind it.
