# Roadbook symbol sources

The symbols drawn in the stage builder, the roadbook editor and the in-game
apps are an unofficial set made for this project. They are inspired by the
public FIM / FIA / Dakar lexicons listed in `SOURCES.md`.

- `NOTES.md` — our own short summary of the roadbook conventions we follow,
  with a tag on each point naming the source document.
- `SOURCES.md` — title, edition, publisher and link for each document.

Official regulation PDFs, page scans and text extracts are **not** stored in
this public repository (those documents belong to their publishers). Use the
links in `SOURCES.md` to read the originals.
